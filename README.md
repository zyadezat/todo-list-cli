# 📋 Python To-Do List CLI Application

A clean, modular command-line To-Do List application built with Python. Designed with robust input validation and user-friendly console interaction.

## ✨ Features
- **Task Management**: Add, view, and delete daily tasks easily.
- **Input Validation**: Prevents empty task entries and handles invalid option choices smoothly.
- **Error Handling**: Uses `try/except` blocks to prevent crashes during index selection.
- **Clean Interface**: Console pauses between operations for better readability.

## 🛠️ Concepts & Technologies
- Python 3.x
- Data Structures: Lists
- Control Flow & Loops
- Exception Handling (`ValueError`, `IndexError`)
